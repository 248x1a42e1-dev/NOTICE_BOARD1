KHIT Notice Board 📢

Flutter-Based College Notice Board Application

Project Overview

KHIT Notice Board is a Flutter-based mobile application developed to help students access college notices in one place.

The application allows students to view notices, search for information, filter notices by category, and access notice details. Administrators can manage notices through the application.

Features

- Student Login: Students can access the notice board.
- Admin Login: Administrators can manage notices.
- Notice Browsing: View available college notices.
- Search Notices: Search notices using keywords.
- Category Filtering: Filter notices by category.
- Notice Details: View complete notice information.
- Add Notices: Administrators can add new notices.
- Edit Notices: Update existing notices.
- Delete Notices: Remove notices with confirmation.
- Local Data Storage: Save application data using SharedPreferences.
