📢 KHIT Notice Board

Flutter-Based College Notice Board Application

<p align="center">
  <strong>Stay Informed, Stay Connected!</strong>
</p>📌 Project Overview

KHIT Notice Board is a Flutter-based mobile application developed to help students access college notices in one place.

The application allows students to view notices, search for information, filter notices by category, and access complete notice details. Administrators can manage college announcements through the application.

✨ Features

- Student Login: Students can access the college notice board.
- Admin Login: Administrators can manage notices.
- Notice Browsing: View available college announcements.
- Search Notices: Find notices using keywords.
- Category Filtering: Filter notices by category.
- Notice Details: View complete notice information.
- Add Notices: Administrators can publish new notices.
- Edit Notices: Update existing announcements.
- Delete Notices: Remove notices with confirmation.
- Local Data Storage: Store application data using SharedPreferences.

⚙️ Installation and Setup

Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio or VS Code
- Android SDK
- Android Emulator or Android Device

1. Clone the Repository

git clone YOUR_GITHUB_REPOSITORY_URL

2. Open the Project

cd campus_connect

3. Install Dependencies

flutter pub get

4. Run the Application

flutter run

5. Run Flutter Tests

flutter test

6. Build APK

flutter build apk --release

Generated APK location:
